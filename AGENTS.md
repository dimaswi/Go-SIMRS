# Aturan & Instruksi Kerja Proyek

- **Pengeditan File**:
  - Dilarang keras menggunakan eksekusi skrip Node.js (`node -e` atau file skrip helper Node) untuk melakukan manipulasi atau pengeditan file kode proyek.
  - Wajib selalu menggunakan tool editor bawaan (`replace_file_content`, `multi_replace_file_content`, atau `write_to_file`) secara langsung.

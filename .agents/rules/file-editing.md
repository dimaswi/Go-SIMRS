# Aturan Pengeditan File

1. **Dilarang Menggunakan Script Node untuk Pengeditan**:
   - Jangan pernah menggunakan command `node -e` atau membuat script Node.js temporary untuk mencari dan mengganti (replace) teks/kode di file proyek.
   - Semua modifikasi kode harus dilakukan langsung menggunakan AI tool editor yang disediakan (`replace_file_content`, `multi_replace_file_content`, atau `write_to_file`).
